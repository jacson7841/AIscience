# 复现与运行说明

## 1. 已验证环境

| 组件 | 已验证版本 |
|---|---|
| OS | Windows 11 x64 |
| Python | 3.13.14 |
| PySpice | 1.5 |
| Ngspice | 46 shared DLL |
| OpenAI SDK | 2.x |
| SchemDraw | 0.23 |

PySpice 1.5 尚未把 Ngspice 46 加入版本白名单，因此可能打印
`Unsupported Ngspice version 46`。本项目的 RC、Task 19 和 LM358 测试均实际执行成功，该文本在
这里被视为已知兼容性告警，不等于仿真失败。

## 2. 创建环境

```powershell
conda env create -f environment.yml
conda activate analogcoderpro
```

已有 Python 3.13 环境也可以执行：

```powershell
pip install -r requirements.txt
```

## 3. 配置 Ngspice

PySpice 使用 Ngspice shared DLL；`ngspice_con.exe` 只用于命令行基础检查。

```powershell
$env:NGSPICE_DLL_PATH='C:\path\to\ngspice.dll'
$env:NGSPICE_EXECUTABLE='C:\path\to\ngspice_con.exe'
```

如果未设置 `NGSPICE_EXECUTABLE`，环境检查脚本会从 `PATH` 搜索 `ngspice_con.exe` 或
`ngspice`。`NGSPICE_DLL_PATH` 未设置时，运行时会尝试项目内的
`vendor/ngspice-46-dll/Spice64_dll/dll-vs/ngspice.dll`，但 Git 仓库不提交 DLL。

## 4. 配置百炼 API

```powershell
$env:DASHSCOPE_API_KEY='仅在当前终端设置'
$env:BAILIAN_BASE_URL='https://dashscope.aliyuncs.com/compatible-mode/v1'
```

禁止把 Key 写入 `.py`、`.ps1`、`.env` 或运行记录。测试 Key 一旦出现在聊天、截图或提交历史中，
应立即撤销并重新生成。

## 5. 基础检查

```powershell
python repro_tools\check_environment.py
```

该命令检查依赖和 Ngspice 路径，并执行 5 V、1 kOhm/1 kOhm 分压器工作点仿真，预期输出
2.5 V。报告保存到 `run_artifacts/environment_check.json`。

## 6. 运行官方 Task 19

```powershell
powershell -ExecutionPolicy Bypass -File repro_tools\run_task19.ps1
```

脚本会：

1. 检查已有的正式 `run_record.json`。
2. 把没有完成记录的目录归档为 interrupted，不计入正式运行。
3. 继续运行直到累计三次独立实验。
4. 每次最多包含一个初始候选和三次修复。
5. 成功后自动导出网表、结构 JSON 和原理图。

## 7. 运行 LM358 类任务

```powershell
powershell -ExecutionPolicy Bypass -File repro_tools\run_lm358.ps1
```

该脚本自动选择下一个 run ID。测试台测量偏置、100 Hz 增益、截止频率、10 kHz 衰减和瞬态
输出范围，五项全部通过才判定成功。

## 8. 无 API 复核成功设计

```powershell
python evaluation\lm358_conditioner\checker.py `
  deliverables\lm358_success\design.py `
  --artifact-dir run_artifacts\lm358_recheck
```

Task 19 参考基线：

```powershell
python deliverables\task19_success\verify_official.py
```

## 9. 原理图导出

```powershell
python repro_tools\schematic\export_from_pyspice.py `
  deliverables\lm358_success\design.py `
  --output-dir run_artifacts\schematic_export
```

输入 Python 文件必须暴露全局 `circuit`，或定义无参可调用的 `build_circuit()`。导出目录包含：

- `circuit.cir`
- `netlist_structure.json`
- `schematic.svg`
- `schematic.png`
- `schematic_manifest.json`

## 10. 常见问题

### 找不到 `pyspice_runtime`

从项目根目录运行脚本，或把项目根目录加入 `PYTHONPATH`。PowerShell 入口会自动处理该路径。

### 找不到 Ngspice DLL

确认 `NGSPICE_DLL_PATH` 指向真实的 `ngspice.dll` 文件，而不是上级文件夹。

### VLM 超时

主闭环会记录视觉模型错误并继续使用仿真文本反馈；该情况不需要手动删除整个实验目录。

### 401/403

认证错误不会重试。检查 Key 所属百炼工作空间和 compatible-mode 端点，认证失败的启动不应计入
电路任务成功率。
